mTriad: Working Memory and Learning

Working memory is the small mental workspace we use to hold and manipulate information for a few seconds. Researchers test it with tasks like the n-back, where you decide whether the current item matches the one shown n steps earlier.

What memory research suggests for students

  • Break study material into small chunks.
  • Use spaced practice instead of cramming.
  • Test yourself with practice questions rather than rereading.
